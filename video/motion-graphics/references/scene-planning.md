# Authoring schema and visual decisions

The authoritative file has `schemaVersion:1`, `style:"editorial-collage"`, `mode:"transcript"|"standalone"`, `assets`, `graphicsPlan:{scenes:[...]}` and optional `authoredOverrides`. Use the concrete [mountain fixture](../tests/fixtures/mountain-plan.json), [sparse transcript preview](../tests/fixtures/preview-plan.json), or [diagram fixture](../tests/fixtures/diagram-plan.json) as schema examples.

Read the complete brief/transcript first. Choose one focal subject and at most two subordinate accents per compact scene. Leave useful gaps. An image, icon or idea can be selected without a document or data source. Claims, actual evidence and quotations must retain supplied/sourced meaning; ambiguous specifics are omitted with a reason.

Scene fields: stable safe `id`; installed `component`; `selectionReason`; timing and source references where applicable; `order`; `placement:{x,y,width,height}` in design pixels; `sceneMode` (default overlay); optional explicit full-screen `background`; `surface` (none/paper/window); ordered `layers`; optional `content.label`, `content.nodes`, `sourceLabel`, `annotations`; `camera:{x,y,zoom}`; `depthStrength`; `motion`; and `paperTreatment`. Only the five catalog components are supported. Arrays replace under overrides; objects merge.

Assets have stable `id`, local `path` relative to the plan, `kind` (illustration/supplied/documentary/mask/texture), `provenance` and `license` (including unknown supplied rights honestly). Preserve original source assets and separately record derived cuts/masks and preparation. Attachment freezes copies and hashes. Vectors must be passive and self-contained; no external fonts/scripts/images. Generate illustration as illustration, never fake documentary evidence.

Each layer has `id`, `asset`, optional `mask`, `depth` (0–4), `rect`, normalized `pivot:[x,y]`, optional `crop:{x,y}` object-position percentages. A covering far/foreground plane uses `coverage:"window"` and `preparedBacking` describing actual coverage preparation. Compiler validates the window at both endpoints under linear coherent motion; subject layers must remain inside the window for the complete path. Do not label a hole-filled image prepared unless it actually is. If backing is missing, reduce travel, choose another crop, use one honest flat reveal or request clean layers.

Camera travel is scene-local; depth scales relative travel and zoom. A parallax scene requires distinct depths and nonzero camera movement. The fixture's camera x=20 and depths .6/1.5/3 resolve to 12/30/60px. This is authored calibration, not a reference measurement. Text remains fixed in the scene; callout endpoints with `layerId` follow that layer. Each annotation has `label`, `from:[x,y]`, `to:[x,y]`, optional `width`, `layerId` and `eventId`.

Overrides resolve style defaults → project overrides → scene overrides → component overrides. Authored scene fields are explicit baseline choices. `authoredOverrides.scenes.<id>.components.<component>` targets one real component. Allowed fields are listed by the validator; unsupported fields fail. `asset` replaces the one layer in a single-layer treatment; `layers` replaces the complete stack. `cameraTravel` changes the x endpoint. The mountain fixture demonstrates a valid targeted override. Source ranges, factual content and protected-region invariants cannot be bypassed.

Paper options: `textureSeed` or local `textureAsset`, `textureStrength` (0–.3), `internalPaperOpacity` (.85–1), `tint`, `edgeShadow` (0–24), `documentTilt` (±5°), `backingSheet`. A deterministic low-contrast fiber pattern is frozen at compile time. It covers the print too; labels render above it. Use zero tilt/texture for small text, preserve meaningful image color and disable material if details lose clarity. No invented marks, animated noise or shadows on unknown footage.

Geometry is premeasured at runtime. Reflow before reducing sizes, never below 36 design px. Reserve full bounds, tilt, shadow, entrance and exit before rendering. Use margins 64 and optional card padding 40. If protected regions or labels fail, revise authored placement/content and compile again; there is no automatic semantic relayout.
